# 💀 RoastMeAI

RoastMeAI is a simple web app that generates funny roast-style responses based on user input. Built with Flask, it delivers instant humor directly in the browser.

---

## 🚀 Features
- ⚡ Instant roast generation
- 😂 Funny randomized responses
- 🌐 Web-based (no install needed)
- 📱 Mobile-friendly UI
- 📋 Copy result feature (optional upgrade)
